One funny line, whole on its own: My password manager forgot my password, so it emails me every morning to ask if I remember it — and it CCs my boss, just in case he does. The program in `main.ts` writes that single line (137 characters) to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
